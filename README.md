# Blitz and Chips: Las notas

Juego de aventura en el navegador. Eres el padre de un niño que parece haber aprobado todo... hasta que a las 18:00 llega el Gmail con la verdad: 7 suspensos. Búscalo por el arcade, sigue su voz por el laberinto y dale la bronca del siglo.

## Controles
- Flechas / WASD: moverte
- E: interactuar
- Espacio / Enter: avanzar diálogos
- R: reiniciar al terminar

## Cómo jugarlo
Abre `index.html` en el navegador, o publícalo con GitHub Pages
(Settings → Pages → Branch `main` → carpeta `/root`).

El laberinto se genera aleatoriamente en cada partida, así que tardas más o menos en encontrar a tu hijo según por dónde vayas.
